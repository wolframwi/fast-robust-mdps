# Benchmark instances

This folder collects standard benchmark MDPs used in experiments and runtime
comparisons.

Structure:
- Each subfolder (e.g., `gridworld25`, `riverswim6`) contains a specific
  benchmark instance plus a local `description.md` with instance details.
- Ambiguity-set files (e.g., `moderate.amb`) are stored alongside the instance
  data.

These benchmarks are referenced by the runtime manifests and evaluation scripts
throughout the repository.
